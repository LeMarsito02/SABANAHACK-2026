# 🎓 Recursos gratis o con descuento para estudiantes — Sabana Hack

Lista de herramientas, créditos y suscripciones gratis o con descuento que pueden aprovechar durante la **Sabana Hack** (y después) por ser estudiantes.

> **Verificación:** salvo que se indique otra cosa, todos los beneficios requieren un **correo institucional (.edu)** o el **[GitHub Student Developer Pack](https://education.github.com/pack)**. Muchos de estos beneficios se reclaman directamente desde el Pack.
